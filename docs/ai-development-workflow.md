# V2 自學開發流程

目標：由你自己理解、寫程式同修正，Codex 做導師。預設唔直接替你完成任務。

## 每次點用

1. 喺 V2 專案打開 Codex，講想學或想改嘅內容。
2. Codex 先讀相關程式，簡短解釋資料流，畀一個細步驟或提示。
3. 你自己寫，貼返修改或叫佢睇目前 diff。
4. Codex review 你嘅嘗試，解釋問題原因，逐步增加提示；等你自己改。
5. 你要求驗證時，協助執行唔會自動改檔嘅檢查並解釋結果。
6. 最後由你用自己說話解釋做法，再決定下一步。

唔使每次重貼導師指令：合併規則後，專案 AGENTS.md 會設定預設行為。新 session 請確認開緊正確 Repository。未合併前，可以 checkout 此 PR 分支，或喺當前 chat 明確要求導師模式。

## 可以直接講

- 「教我理解商品列表由 API 去到畫面嘅流程，每次只講一部分。」
- 「我想自己加商品搜尋，畀我第一個提示，唔好直接改檔或貼完整解答。」
- 「睇我目前 diff，指出問題，先畀提示等我自己修正。」
- 「幫我跑 frontend lint 同 build，解釋結果，唔好自動修正。」
- 「呢部分我想睇完整答案，請提供並解釋。」
- 「今次請直接幫我實作〔明確範圍〕，完成後逐段教返我。」

最後兩種係你主動要求完整答案或代寫；完成該範圍後，下一個任務返回導師模式。

## 驗證現況

Frontend 指令：喺 frontend 執行 `npm run lint` 同 `npm run build`。目前已檢視基線冇設定自動測試 suite；唔可以將不存在嘅測試報成通過。Backend 啟動會建立 DB 表格，驗證前先確認隔離環境。

金額邏輯可先自己手算：POS=10000、CAT=9790、取消=1400，目標=1190；相反方向 POS=9790、CAT=10000、取消=1400，目標=1610。由你解釋原因，再對照程式。

[學習任務模板](templates/task.md) 可留喺 chat；只有你要求先存檔。遇到規則衝突，以明確授權及 AGENTS.md 嘅導師模式為準。
